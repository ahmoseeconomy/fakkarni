# مشية الجهاز الحقيقي — حساب أب نضيف على iPhone saad

الهدف: نمشي على الـ٣٣ شاشة بترتيب التطبيق (مش ترتيب أرقام الملفات)، وكل
واحدة نقارنها بلقطتها في `design/handoff/screenshots/`.

**اللي الجهاز الحقيقي بيفتحه ومحاكي مش قادر:** الكاميرا (٠٥ و٠٧)، الإشعار
وهو بيرنّ فعلاً والتطبيق مقفول، وأحجام الخط على شاشة حقيقية.

القاعدة: لو الفرق **مقاس أو مسافة**، اكتبه وكمّل. لو الفرق **جملة أو
ترتيب أو زرار**، وقف واكتبه بالتفصيل — ده اللي بيتصلح قبل الديمو.

## أ) الدخول والتعريف
- [ ] `01-splash` — الشعار والأنيميشن. يقيس: مدة الوقفة، مش بطيئة.
- [ ] `02-account-type` — «مين ماسك التليفون ده؟» تلات اختيارات.
- [ ] `03-login` — من «بظبّط لحد تاني» أو «عندي كود».
- [ ] `21-name-age` — الاسم والسن. **جرّب تكتب سن غلط (٥٢٠) وشوف بيحصل إيه.**
- [ ] أسئلة الروتين الخمسة — صحيان/فطار/غدا/عشا/نوم.

## ب) اليوم
- [ ] `04-home` / `22-your-day` — «يومك» بعد الروتين على طول، وهي فاضية.
- [ ] `24-today-rail` — شريط اليوم بمراسيه.
- [ ] `20-add-dose` — «+ ضيف».
- [ ] `23-dose-editor` — محرر الجرعة بالمرساة والإزاحة.
- [ ] `09-meds-schedule` — لستة الأدوية وقواعدها.

## ج) الذكاء الاصطناعي — **الأهم على جهاز حقيقي**
- [ ] `05-scan-rx` — صوّر روشتة **حقيقية**. الكاميرا نفسها، مش صورة من المعرض.
- [ ] `06-ai-review` — «فهمت الروشتة كده». شوف الثقة القليلة بتبان إزاي.
- [ ] جرّب ورقة **مش روشتة** — لازم يقول «مش قادر أقرا»، ما يخترعش أدوية.
- [ ] `07-scan-lab` — تصوير تقرير تحليل.
- [ ] `08-lab-reading` — النتايج المقروءة قبل التأكيد.

## د) الملف الصحي
- [ ] `13-records` · `28-manual-entry` · `29-history`
- [ ] `11-checkup` — دورة الفحص ومراحلها.
- [ ] `12-calendar` — التقويم الموحّد.
- [ ] `14-glucose` — **جرّب ٥٢٠ وشوف التطبيق بيعترض ولا لأ.**

## هـ) الرعاية والتصعيد

- [ ] `26-notifications` — **إذن الإشعارات: شكل الطلب على جهاز حقيقي.**
- [ ] `10-alert` / `27-alert-card` — التنبيه.

      وسيب التليفون. لازم يرنّ. لو ما رنّش، ده أخطر اكتشاف في المشية كلها.
