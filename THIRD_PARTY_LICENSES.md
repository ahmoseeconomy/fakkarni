Review each of these before any public release.

**Read the `reached via` path first.** If it passes through a
`*_linux`, `*_windows` or `*_macos` package, this is desktop
support for a plugin we use on mobile — the code is resolved by
pub but is not compiled into the Android/iOS binaries. If the
path does **not** go through one of those, the package is a
direct dependency of something we really ship and needs a closer
look.
