# فكرني — سكريبت الصوت: «بيسمع» و«بيفهم» (المرحلة ٢ و٣)

**الصوت:** ممدوح (ElevenLabs — Deep Egyptian Arabic Male) · **اللهجة:** مصري زي البيت · **المخاطبة:** «حضرتك»
**زي قبل كده:** كل سطر = ملف لوحده باسم الرقم + `.mp3`، والجملة تتقري بالحرف.

> الجمل اللي فيها اسم دوا أو ساعة (زي «فهمت: تضيف دوا الضغط الساعة ٨ الصبح. صح كده؟») **مش هتتسجّل**،
> صوت الموبايل هو اللي بيقولها، لأنها بتتغير كل مرة.

---

## المرحلة ٢ — بيسمع (إجابات قصيرة: أيوه/لأ، ساعة، رقم)

| الرقم | الجملة | إمتى |
|---|---|---|
| `lis_intro` | دلوقتي تقدر تكلّمني. دوس على زرار الميكروفون، وقول إجابتك، زي «تمانية الصبح». | أول مرة بس يظهر زرار الميكروفون |
| `lis_listening` | اتكلم، أنا سامعك. | لما يدوس الميكروفون |
| `lis_not_understood` | معلش، مافهمتش. ممكن تقولها تاني، أو تدوس بإيدك. | لو الكلام مااتفهمش |
| `lis_confirm` | صح كده؟ | بعد ما يقول اللي فهمه بصوت الموبايل |
| `lis_mic_permission` | عشان أسمع حضرتك، محتاج إذن الميكروفون. دوس «سماح». | قبل طلب الإذن من الموبايل |
| `lis_mic_denied` | مفيش مشكلة، تقدر تكمّل بإيدك عادي. | لو رفض الإذن |

## المرحلة ٣ — بيفهم (طلبات مفتوحة)

| الرقم | الجملة | إمتى |
|---|---|---|
| `cmd_hint` | تقدر تقولّي مثلاً: «ضيفلي دوا الضغط الصبح بعد الفطار»، أو «أخدت دوا السكر»، أو «إيه دوايا الجاي؟». | أول مرة يدوس «كلّمني» |
| `cmd_thinking` | ثانية واحدة. | وهو بيفهم الطلب |
| `cmd_cancelled` | تمام، مش هعمل حاجة. | لو قال «لأ» أو «إلغي» |
| `cmd_done` | تمام، عملتها. | بعد ما ينفّذ |
| `cmd_limit` | كفاية كده النهارده. كمّل بإيدك، وبكرة نتكلم تاني. | لو خلص الحد اليومي |

**موجودين قبل كده وهيتستخدموا تاني:** `gen_no_medical` (سؤال طبي) · `gen_try_hands` (مفيش نت أو مافهمش) · `help_confirm_done` (بعد «أخدته» بالصوت).
